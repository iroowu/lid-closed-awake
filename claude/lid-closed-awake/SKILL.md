# 闔蓋不睡（lid-closed-awake）

讓 Mac 筆電闔上蓋子也繼續工作。最常見的用途：把電腦留在家裡或辦公室、闔上蓋子出門，
用手機的 Claude App 透過 Remote Control 繼續指揮電腦上的 Claude 做事。

用白話跟使用者說話，少用術語。使用者多半不是工程師。

## 先講清楚的三件事

1. **改睡眠開關要這台 Mac 的登入密碼，一律由使用者自己輸入。**
   ⛔ 不要叫使用者把密碼告訴你，⛔ 不要替他打。你的工作是查狀態、說明、帶路、驗收。
2. 這些開關只在使用者自己的 Mac 上有效。你如果跑在 claude.ai 網頁或雲端環境、碰不到他的電腦，
   就帶他照下面的步驟自己點，做完請他把「查看狀態」的結果貼回來給你看。
3. 這個 skill 只適用 Mac 筆電。桌機、Windows 不適用，直接說明。

## 流程

### 1. 先查狀態（唯讀，不改任何設定）

```bash
bash "<這個 skill 的資料夾>/scripts/status.sh"
```

把八項結果翻成白話講給使用者聽：闔蓋睡眠、電池保護、電源、蓋子、進階畫面不上鎖、螢幕上鎖、Claude 桌面版、網路。
最後一行「結論」會說還差哪一步。

### 2. 說明會做什麼、代價是什麼，問他要不要開

會做的事：
- 把系統的「闔蓋睡眠」關掉（`pmset -a disablesleep 1`）。Mac 預設闔蓋就睡，一般的防睡指令（caffeinate）擋不住這一步，所以要改這個開關。
- 裝「電池保護」：系統每 60 秒看一次，用電池且電量 ≤ 20% 時自動改回闔蓋會睡，蓋子闔著就讓電腦去睡；插上電再自動改回闔蓋不睡。

一定要講的代價與安全須知：
- 闔蓋不睡用電池會一直耗電，長時間闔蓋請插電。
- ⛔ 不要把醒著的電腦塞進包包、悶在棉被裡，會過熱。闔蓋時鍵盤那一面散熱差，剪片、大量轉檔這種重工作最好墊高或留縫。
- 帶著電腦出門，先關掉（點「關閉闔蓋不睡.command」）。

### 3. 使用者同意後，請他自己執行

給兩種做法，讓他挑順手的：

- **點兩下**：在 Finder 打開這個 skill 的資料夾，點兩下「開啟闔蓋不睡.command」，照畫面輸入登入密碼。
  可以替他打開資料夾：`open "<這個 skill 的資料夾>"`。
- **終端機**：請他打開「終端機」，貼上下面這行、按 Return、輸入登入密碼（打字時畫面不會出現符號，是正常的）：

  ```bash
  sudo /bin/bash "<這個 skill 的資料夾>/scripts/install.sh"
  ```

點兩下時如果出現「無法打開，因為 Apple 無法檢查是否包含惡意軟體」：這是從網路下載的檔案都會有的提醒。
請他到「系統設定 → 隱私權與安全性」，往下捲找到這個檔案，按「強制打開」；或改用終端機那一行。
⛔ 不要自己替他關掉 Gatekeeper 或刪除檔案的隔離屬性。

### 4. 他說好了，再查一次狀態驗收

再跑一次 `status.sh`。要看到：① 闔蓋睡眠「已關掉」、② 電池保護「有在跑」。
沒看到就照輸出說的補，⛔ 沒驗過不要說「開好了」。

### 5. 建議做一次三分鐘闔蓋測試

請他點兩下「闔蓋測試_3分鐘.command」（或跑 `bash scripts/heartbeat_test.sh 3`），然後闔上蓋子至少 2 分鐘再打開。
它每 10 秒記一次時間、蓋子狀態、連不連得到 Claude。結果：
- ✅ 通過：闔蓋期間電腦一直醒著、網路也通。
- ❌ 中間停了很久：電腦有睡著，回第 1 步查狀態。
- ⚠️ 沒偵測到闔蓋：請他重測，這次記得把蓋子闔上。

### 6. 提醒手機遙控（Remote Control）的設定

闔蓋不睡只負責「電腦醒著」。要從手機遙控，另外還要：
- 付費方案：Remote Control 需要 Pro、Max、Team 或 Enterprise（用 API 金鑰不行）。
- 電腦上的 **Claude 桌面版要開著**（官方說明：電腦要開著、Claude 的程序要一直在跑）。
- 在 Claude 桌面版的 **Code** 分頁對話框打 `/remote-control`（或 `/rc`）；
  想讓每個新對話都自動連上，到 **設定 → Code（或 Claude Code）** 打開「Connect new sessions to Remote Control」。
- 手機打開 Claude App，就能看到並接手電腦上的那個對話。
- 官方說明：<https://code.claude.com/docs/en/remote-control>

### 7. 進階：闔蓋時畫面不上鎖（只有要操作畫面才需要）

闔蓋不睡之後，系統醒著，但闔蓋約 3 分鐘螢幕睡著時 Mac 會上鎖。上鎖以後：
- 不碰畫面的工作照跑：手機遙控聊天、讀寫檔案、排程、下載、連線服務。
- 要操作畫面的工作會卡住：點 App 視窗、用瀏覽器、螢幕錄影。

需要後者才開：點兩下「進階_闔蓋時畫面不上鎖_開啟.command」（不需要密碼）。
它在蓋子闔著時讓顯示器保持醒著（`caffeinate -d`），打開蓋子立刻放手，電量 ≤ 20% 也放手。
⛔ 一定要講代價：闔蓋期間畫面沒鎖，別人這時打開蓋子不用密碼就能進桌面。帶出門前要關。

### 8. 還原

點兩下「關閉闔蓋不睡.command」，或終端機：

```bash
sudo /bin/bash "<這個 skill 的資料夾>/scripts/uninstall.sh"
```

會移除電池保護、改回闔蓋會睡（Mac 的預設值），也一併關掉進階選項。

## 已實測的事（作者的 MacBook，macOS 26，2026 年 8 到 10 月）

- `pmset -a disablesleep 1` 之後闔蓋不睡：每 15 秒一筆心跳、闔蓋期間零中斷，Wi-Fi 沒斷，背景程式持續連網。
- 用電池闔蓋也不睡，而且會一直耗電到底，所以才加電池保護。
- 電量保護的做法（改回 `disablesleep 0` 後，蓋子闔著再下 `pmset sleepnow`）實際讓電腦睡下去過。
- 闔蓋本身不會上鎖；上鎖發生在闔蓋約 3 分鐘、螢幕睡著的時候（系統紀錄 kLWLockFromDisplayDim）。
- 闔蓋時掛 `caffeinate -d`，顯示器不睡，就不會上鎖；實測闔蓋 200 分鐘顯示器都沒關。
- 顯示器睡著時，螢幕錄影（OBS）的畫面和聲音會凍住，喚醒也不會自己恢復。要闔蓋錄影，就要開進階選項。

## 要知道的限制

- `disablesleep` 不在 Apple 的官方說明書（`man pmset`）裡。系統大改版後，請重跑一次闔蓋測試確認還有效。
- 闔著蓋子時改睡眠設定，可能要等下一次開關蓋才生效（網路上的說法，作者沒有完整實測）。電池保護遇到這種情況會直接下 `pmset sleepnow`。
- 電腦真的睡著或斷網時，手機那頭會連不上；官方說明是電腦醒來、網路回來後會自動重新連上。
- Apple 內建的「闔蓋模式」（接外接螢幕、鍵盤、電源）本來就能闔蓋工作，有外接螢幕的人不一定需要這個工具。

## 檔案

| 檔案 | 做什麼 | 要密碼嗎 |
|---|---|---|
| `開啟闔蓋不睡.command` | 關掉闔蓋睡眠＋裝電池保護 | 要 |
| `關閉闔蓋不睡.command` | 全部還原 | 要 |
| `查看狀態.command` | 看八項狀態（只讀） | 不用 |
| `闔蓋測試_3分鐘.command` | 三分鐘闔蓋測試 | 不用 |
| `進階_闔蓋時畫面不上鎖_開啟.command`／`_關閉.command` | 闔蓋時畫面保持醒著 | 不用 |
| `scripts/` | 上面這些按鈕實際跑的程式，只用 macOS 內建指令 | |

裝在系統裡的位置（還原時都會刪掉）：
`/Library/Application Support/LidClosedAwake/`、`/Library/LaunchDaemons/local.lidclosedawake.guard.plist`、
進階選項在 `~/Library/Application Support/LidClosedAwake/` 與 `~/Library/LaunchAgents/local.lidclosedawake.display.plist`。
紀錄在 `/Library/Logs/LidClosedAwake.log`、`~/Library/Logs/LidClosedAwake-display.log`。
